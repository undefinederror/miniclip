# Commands

| Command | Description |
|---|---|
| `npm run dev` | Start Vite dev server with Electron |
| `npm run build` | Full production build (tsc → vite build → scripts/build.mjs) |
| `npm run build:publish` | Build + publish to GitHub/Snap Store |
| `npm run lint` | ESLint check (ts, tsx — zero warnings allowed) |
| `npm run preview` | Preview production build |
